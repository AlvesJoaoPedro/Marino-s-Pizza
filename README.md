# 🍕 Sistema de Gerenciamento de Pizzaria Tradicional

![Preview do Sistema](https://github.com/AlvesJoaoPedro/Marino-s-Pizza/blob/main/preview.png)

## 📋 Descrição

Este projeto tem como objetivo desenvolver um sistema para o gerenciamento de uma pizzaria tradicional, com foco em automatizar e facilitar o controle de pedidos, cardápio, clientes e entregas. A aplicação simula o funcionamento de uma pizzaria de estilo clássico, oferecendo recursos que refletem a rotina de atendimento tanto presencial quanto por delivery.

## 🔧 Funcionalidades Principais

- Cadastro e gerenciamento de pizzas (sabores, tamanhos, preços, ingredientes)
- Cadastro de clientes e seus dados de contato
- Registro e acompanhamento de pedidos
- Opção de pedidos para consumo no local, retirada ou entrega
- Sistema simples de autenticação para funcionários
- Interface intuitiva voltada à operação em tempo real
